# 里程碑 M4 — 下一目标规划（体验与治理）

> 前置：[M3 完成说明](./milestone-M3-completion.md) 已验收  
> 依据：Phase 0.5 UI/UX、产品规划 V2 §P1、M2 预告表  
> 日期：2026-09-14  
> 状态：**待启动**

---

## 1. 一句话目标

**把「能用」做成「好协作、可追溯」：成员体验、审计与错误可理解性、上传过程可见。**

---

## 2. Must（必须）— 初稿，开工前可微调

1. **知识库成员体验**
   - 可选用户列表 / 搜索后添加成员（避免只能手填 UUID）
   - 角色变更与移除路径清晰  
2. **错误文案体系**
   - 前端对常见 `code`（解析失败、权限、配额、未 READY）有稳定中文提示  
3. **上传 / Job 进度可见**
   - 文档列表或详情能感知处理中 / 成功 / 失败原因（对齐现有 Job API）

---

## 3. Should

- 审计日志写入关键写操作（上传、删文档、改成员）；管理端只读查询可后置  
- 会话/Citation 边角体验小修（角标与侧栏一致性说明等）  

---

## 4. Won’t

- 完整系统管理后台（组织/角色/权限 CRUD 全套）  
- Redis / Celery / MinIO  
- OCR、Rerank、Hybrid Search、完整 CD 部署流水线  

---

## 5. 退出标准（草案）

```text
□ 管理员可为 KB 通过用户搜索添加/移除成员
□ 上传失败与解析失败有可读错误（非裸 UUID/堆栈）
□ 文档处理状态在 UI 可感知（至少轮询 Job 或列表状态）
□ plan 完成说明 + 回归不破坏 M1–M3 主路径
```

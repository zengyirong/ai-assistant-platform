> 前置：[M3 完成说明](./milestone-M3-completion.md) 已验收

---

## 1. 一句话目标

**把「能用」做成「好协作、可追溯」：成员体验、审计与错误可理解性、上传过程可见。**

---

## 2. Must（必须）

1. **知识库成员体验**
   - [x] `GET /api/v1/users` 组织内用户搜索  
   - [x] 成员选择器（remote search）+ 人名展示 + 行内改角色 / 移除  
2. **错误文案体系**
   - [x] 前端 `code` → 中文映射（拦截器 + Job 失败弹窗 + Chat SSE）  
3. **上传 / Job 进度可见**
   - [x] 文档列表附带 `latest_job`（进度 % / 阶段；失败可读原因）  

---

## 3. Should

- [ ] 审计日志写入关键写操作（上传、删文档、改成员）；管理端只读查询可后置  
- [ ] 会话/Citation 边角体验小修（角标与侧栏一致性说明等）  

---

## 4. Won’t

- 完整系统管理后台（组织/角色/权限 CRUD 全套）  
- Redis / Celery / MinIO  
- OCR、Rerank、Hybrid Search、完整 CD 部署流水线  

---

## 5. 退出标准

```text
☑ 管理员可为 KB 通过用户搜索添加/移除成员
☑ 上传失败与解析失败有可读错误（非裸 UUID/堆栈）
☑ 文档处理状态在 UI 可感知（列表 latest_job + 轮询）
□ plan 完成说明 + 回归不破坏 M1–M3 主路径（待验收后固化）
```

本地验收建议：

1. 知识库详情 → 成员：搜索用户添加 / 改角色 / 移除  
2. 上传文档：列表出现「解析中 xx%」；失败点「原因」见中文文案  
3. 故意上传非法格式：前端提示映射后的中文
